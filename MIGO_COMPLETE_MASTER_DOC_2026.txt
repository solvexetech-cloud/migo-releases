## 1. PROJECT OVERVIEW (പ്രോജക്ട് അവലോകനം)
MIGO എന്നത് ഒരു ഹൈപ്പർലോക്കൽ ഡീൽസ്, കമ്മ്യൂണിറ്റി ഡിമാൻഡ്, കോയിൻ റിവാർഡ് പ്ലാറ്റ്ഫോം ആണ്. ഇതിൽ 3 പ്രധാന ആപ്പുകൾ ഉണ്ട്:
1. **Customer App (Flutter):** ഉപഭോക്താക്കൾക്ക് ഡീലുകൾ കാണാനും, കമ്മ്യൂണിറ്റി ഡിമാൻഡുകൾ ഉണ്ടാക്കാനും, കോയിൻസ് സമ്പാദിക്കാനും ഉള്ളത്.
2. **Business App (Flutter):** കടകൾക്ക് ഓഫറുകൾ ഇടാനും, QR സ്കാൻ ചെയ്ത് റെഡീം ചെയ്യാനും, ഡിമാൻഡുകൾക്ക് ബിഡ് ചെയ്യാനും ഉള്ളത്.
3. **Admin/Agency Panel (React JS):** സൂപ്പർ അഡ്മിൻ, ഏജൻസികൾ, സ്റ്റാഫ് എന്നിവർക്ക് ആപ്പ് മോണിറ്റർ ചെയ്യാനും, അനലിറ്റിക്സ് കാണാനും, ലൊക്കേഷനുകൾ, തീം എന്നിവ മാനേജ് ചെയ്യാനുമുള്ള വെബ് പാനൽ.

## 2. TECH STACK (ഉപയോഗിച്ച സാങ്കേതികവിദ്യകൾ)
- **Frontend (Mobile):** Flutter (Dart), Mobile Scanner (QR), Geolocator (Location), QR Flutter, Shared Preferences.
- **Frontend (Web):** React.js, Vite, React Router DOM, Inline Styles, React Icons.
- **Backend:** Firebase (Serverless Architecture).
  - Firestore Database (NoSQL)
  - Firebase Authentication
  - Firebase Cloud Messaging (FCM)
  - Firebase Hosting
  - Cloudinary (Image Storage)
- **State Management:** Flutter-ൽ Native setState & ListenableBuilder (Locale), React-ൽ Context API & State.

## 4. DATABASE SCHEMA (ഡാറ്റാബേസ് ഘടന - Firestore)
- users: കസ്റ്റമർ വിവരങ്ങൾ (name, phone, areaId, country, coins, role, location GeoPoint).
- businesses: കടകളുടെ വിവരങ്ങൾ (name, category, countryCode, zoneId, ownerUid, location, trustScore, status).
- offers: കടകൾ ഇടുന്ന ഓഫറുകൾ.
- demands: കസ്റ്റമർ ഇടുന്ന വ്യക്തിഗത ഡിമാൻഡുകൾ.
- demand_groups: ഓട്ടോമാറ്റിക് ആയി ഗ്രൂപ്പ് ചെയ്ത ഡിമാൻഡുകൾ (title, category, zoneId, members, memberCount, threshold, totalQuantity, minTargetPrice, maxTargetPrice, status, deliveryDate, thresholdReachedAt, expiresAt).
- demand_bids: കടകൾ ഇടുന്ന ബിഡുകൾ (offerPrice, minCommitments, businessTrustScore, status, groupTitle, deliveryDate).
- demand_claims: റെഡംപ്ഷന് വേണ്ടിയുള്ള QR/PIN ഡാറ്റ (status, pin, qrData, totalPrice, redeemedAt).
- app_config: ആപ്പ് തീം, ഡിമാൻഡ് സെറ്റിംഗ്സ് (defaultThreshold, demandExpiryDays, privateBulkMinQuantity).
- product_requests, countries, zones, areas, coin_transactions, notifications.

## 5. FEATURES & WORKFLOWS (ഫീച്ചറുകളും പ്രവർത്തനങ്ങളും)

### ✅ പൂർത്തിയായവ:
1. **Authentication:** Firebase Auth ഉപയോഗിച്ച് ലോഗിൻ.
2. **Business Registration:** കാറ്റഗറി തിരഞ്ഞെടുത്ത് രജിസ്റ്റർ ചെയ്യാം. അഡ്മിൻ അപ്രൂവ് ചെയ്യുന്നത് വരെ "Account Under Review" എന്ന് കാണിക്കും.
3. **New Demand System (Confusion-Free):**
   - കസ്റ്റമർ ഡിമാൻഡ് ഇടുമ്പോൾ "Community" / "Private Bulk" എന്ന ടോഗിളുകൾ ഇല്ല.
   - ഓട്ടോമാറ്റിക് ഗ്രൂപ്പിംഗ്: ഒരേ ഐറ്റം + കാറ്റഗറി + സോൺ ഉള്ളവ ഒരുമിച്ച് ചേരും.
   - Bulk Order: ഒരു നിശ്ചിത എണ്ണത്തിൽ (ഉദാ: 10) കൂടുതൽ ആവശ്യപ്പെട്ടാൽ, ഉടൻ തന്നെ ബിസിനസുകാർക്ക് കാണാം.
4. **Business Demands Feed:** ബിസിനസിന് അവരുടെ കാറ്റഗറിയിലുള്ള ഡിമാൻഡുകൾ മാത്രം കാണാം.
5. **Bidding System:** ബിസിനസുകാർ ബിഡ് ഇടാം, എഡിറ്റ് ചെയ്യാം (പഴയ വില കാണിക്കും).
6. **Admin Panel:** ബിഡുകൾ അപ്രൂവ്/റിജക്റ്റ്/ഡിലീറ്റ് ചെയ്യാം. ത്രെഷോൾഡ്, എക്സ്പയറി തുടങ്ങിയവ മാറ്റാം.
7. **QR & PIN Redemption:** കസ്റ്റമർ ഓർഡർ കൺഫേം ചെയ്താൽ QR കോഡും 6 അക്ക PIN-ഉം ലഭിക്കും. ബിസിനസ് ആപ്പിൽ അത് സ്കാൻ ചെയ്ത് റെഡീം ചെയ്യാം.
8. **History (Active / Completed):** കസ്റ്റമർക്കും ബിസിനസിനും റെഡീം ചെയ്ത ഓർഡറുകൾ തീയതിയും സമയവും സഹിതം കാണാം.
9. **Language Support:** ഇംഗ്ലീഷ്, അറബിക് (RTL).
10. **Admin Hosting:** https://migo-app-3030e.web.app

4. **Regex ഒഴിവാക്കുക:** കോഡ് മാറ്റങ്ങൾക്ക് Regex ഉപയോഗിക്കുന്നത് ഒഴിവാക്കുക. പകരം, കൃത്യമായ കോഡ് നൽകുകയോ ഉപയോക്താവിനെ കൈകൊണ്ട് ചെയ്യാൻ അനുവദിക്കുകയോ ചെയ്യുക.

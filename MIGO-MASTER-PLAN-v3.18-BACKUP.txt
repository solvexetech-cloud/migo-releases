## PHASE H — MIGO Reserve (Guaranteed Reservation System)
═══════════════════════════════════════════════════════

### 🎯 ലക്ഷ്യം: D4D-നെ വെല്ലുന്ന Killer Feature

**Philosophy:** Customer-ന് offer **guaranteed reservation** — wait ഇല്ല, doubt ഇല്ല.

### 📋 Core Features

| # | Feature | Description |
|---|---------|-------------|
| 1 | Limited Stock Offers | Shop 10/20/50 items offer ഇടുന്നു (e.g., 10 mobiles @ QAR 1200) |
| 2 | Booking | Customer reserve ചെയ്യുന്നു — guaranteed |
| 3 | Countdown Timer | Booking → offer end വരെ live timer |
| 4 | Time-bound Pickup | Time കഴിഞ്ഞാൽ item auto-release |
| 5 | No-wait Shopping | വരി നിൽക്കേണ്ട, guaranteed item |
| 6 | Shop Dashboard | ഏത് customer, ഏത് time, എത്ര items |
| 7 | Location Lock | ആ area-യിലെ customer-ന് മാത്രം book |
| 8 | Rules Page + Accept | Common rules, accept ചെയ്തേ book ചെയ്യൂ |
| 9 | Multi-role Control | super_admin/admin/agency/mod |
| 10 | No-show Protection | 3 → 7-day ban, 5 → 30-day ban |
| 11 | QR Pickup Verification | Anti-fraud GPS-verified pickup |
| 12 | Push Notifications | 5-stage reminders (0/1h/2h/30m/expiry) |
| 13 | Token Booking (optional) | QAR 10-50 refundable deposit |
| 14 | Group Reserve (bonus) | 5 friends = 5% extra off |

### 🗄️ New Collections

- `reservations/{id}` — {
    userUid, businessId, businessName, offerId, offerTitle,
    quantity, unitPrice, currency,
    bookedAt, expiresAt, pickedUpAt,
    status: reserved/picked_up/expired/cancelled,
    pickupCode, qrCode, notes,
    tokenAmount, tokenRefunded
  }

- `reservation_rules/{id}` — {
    version, title, textEn, textAr, textMl,
    active, updatedAt, updatedBy
  }

- `no_show_log/{id}` — {
    userUid, businessId, businessName, offerId,
    reservationId, timestamp, reason
  }

- `reservation_config/{id}` — {
    enabled: true/false,
    defaultHoldHours: 4,
    maxHoldHours: 24,
    tokenRequired: false,
    tokenAmount: 0,
    noShowLimit7Day: 3,
    noShowLimit30Day: 5,
    banDurationDays: 7,
    locationLockEnabled: true,
    locationLockRadiusKm: 5
  }

### 🗄️ Firestore Indexes (Composite)

- `reservations`: userUid + status + bookedAt DESC
- `reservations`: businessId + status + bookedAt DESC
- `reservations`: businessId + expiresAt
- `reservations`: offerId + status
- `no_show_log`: userUid + timestamp DESC

## ഭാഗം 7: Referral System (Complete)
═══════════════════════════════════════════════════════

### Flow:
1. User A shares referral code (e.g., 3WHT9X)
2. Sends link: migo-app-3030e.web.app/r/3WHT9X
3. User B opens link → landing page
4. Landing shows code + Download button
5. User B downloads APK from GitHub
6. User B signs up with code 3WHT9X
7. User B makes first claim
8. Both get coins (A: +50, B: +30)

### URLs:
- Landing: migo-app-3030e.web.app/r/{CODE}

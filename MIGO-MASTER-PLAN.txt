### 🔗 SECTION A: Referral System (Detailed)

#### A1. Auto-Referral Flow (Install Referrer)

**Target:** User clicks referral link → Auto-install → Auto-apply code (no typing)

**Flow (Not Installed):**
1. User A shares: https://migo-app-3030e.web.app/r/3WHT9X
2. User B clicks link → Web landing page
3. Landing page has:
   - Code: 3WHT9X (visible)
   - "Download MIGO" button
   - Play Store link with referrer: play.google.com/store/apps/details?id=com.migo.app&referrer=ref%3D3WHT9X
   - Alternative: APK download (URL param saved)
4. User B installs APK or Play Store app
5. App first launch:
   - Install Referrer API reads "ref=3WHT9X" (Play Store)
   - Or SharedPreferences reads URL param (APK)
6. Auto-applies code to user account
7. User B signs up → Code already filled
8. User B makes first claim → Both get coins

**Flow (Already Installed):**
1. User B clicks: https://migo-app-3030e.web.app/r/3WHT9X
2. Web landing page detects MIGO installed (deep link ready)
3. Landing page has: "Open in MIGO" button
4. Tap → App opens with deep link
5. Code 3WHT9X applied to existing account
6. If code already applied → Notification "You already have a referral code"
7. Otherwise → Applied successfully

#### A2. Link Format

**Referral Link:**
https://migo-app-3030e.web.app/r/{CODE}

**Offer Share Link:**
https://migo-app-3030e.web.app/o/{offerId}?ref={CODE}

**Play Store Link (with referrer):**
https://play.google.com/store/apps/details?id=com.migo.app&referrer=ref%3D{CODE}

**APK Link (with ref param):**
https://github.com/solvexetech-cloud/migo-releases/releases/download/v1.3.1/MIGO-v1.3.1.apk?ref={CODE}

#### A3. Install Referrer API (Play Store)

**Flutter Package:** android_install_referrer

**Implementation:**
1. App first launch → InstallReferrerService.fetch()
2. Gets: "ref=3WHT9X"
3. Parse referral code
4. Save to SharedPreferences
5. Apply during signup

**Delay:** Play Store referrer available within 10 seconds of first launch.

#### A4. APK Flow (Website)

**Website captures:** URL param `ref=CODE`
**Stores:** Cookie + URL parameter
**Redirects to:** APK download URL with ref param

**APK Install → First Launch:**
- No Install Referrer (not Play Store)
- Alternative: Deep link or manual code entry
- Or use: Referrer URL stored in web cookie + email link

**Best for now:** Manual code entry (simple) + automatic web-based code (if possible)

#### A5. Edge Cases

**Case 1: User already has a referral code**
- New code ignored
- Show: "You already have referral code {existing}"

**Case 2: Self-referral**
- Blocked (same device, IP)
- Show: "Cannot refer yourself"

**Case 3: Multiple clicks**
- First code wins
- Others ignored

**Case 4: Link expired**
- Show: "Link expired"
- Redirect to home

**Case 5: Code not found**
- Show: "Invalid referral code"
- Allow manual entry

#### A6. Reward (Referral)

**User A (Referrer):**
- +50 coins when User B makes first claim

**User B (Referred):**
- +30 coins when makes first claim

**Both get coins on first claim (not signup).**
